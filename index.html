What the past finals actually ask

  • Every paper: an open-heater or multi-heater steam cycle with flow diagram, h–s or T–s diagram and efficiency (Sheet 2 Q6 and Q5).
  • 2024, 2025, 2026: the same six-cylinder diesel test (Sheet 4 Q7). If you learn one thing, learn this one.
  • Economics (Sheet 1) or the boiler drum (Sheet 3 Q1) as Q1; the economizer and air preheater (Sheet 3 Q6) in 2023.
  • One “late-course” question: combined cycle (2023) or a dry cooling tower with a surface condenser (2024).

Exam-day answer layout

  1. Given / Find
  2. Assumptions (steady flow, negligible KE/PE, isentropic pumps, TTD, stack temperature…)
  3. Sketch: flow diagram with state numbers, then T–s or h–s (or p–V for engines)
  4. Property table: state, p, T, h, s, x, with the table used
  5. Steps: formula first, then numbers, then units
  6. Boxed answer and a sanity check (efficiency below Carnot, quality between 0 and 1, heat balance closes)
